# The catalog contract

Websites and tools (for example a studio site showing the library) read the library through one file:

```
https://raw.githubusercontent.com/GTKottman/remotion-transitions/main/catalog.json
```

`catalog.json` is generated by `npm run build` from every `transition.json` and `taxonomy.json`.
CI fails if it is out of date, so whatever is on `main` is current.

## Stability

- `schemaVersion` changes only when a field is removed or changes meaning. Adding fields does not
  change it, so readers should ignore fields they don't know.
- A transition's `id` never changes. If a transition is replaced, the old id is removed and the new
  one names it in `basedOn`.
- Media URLs contain the transition's version, so a URL always shows exactly the version it names.

## Shape

```jsonc
{
  "schemaVersion": 1,
  "repository": "https://github.com/GTKottman/remotion-transitions",
  "mediaBase": "https://github.com/GTKottman/remotion-transitions/releases/download/media",
  "families": [
    { "slug": "04-cover", "name": "Cover", "definition": "…",
      "subfamilies": [{ "slug": "organic", "name": "Organic", "definition": "…" }] }
  ],
  "transitions": [
    {
      "id": "liquid-fill",
      "name": "Liquid Fill",
      "version": "1.0.0",
      "summary": "One sentence.",
      "uses": ["Scene changes", "…"],
      "family": "04-cover",
      "subfamily": "organic",
      "path": "transitions/04-cover/organic/liquid-fill",
      "facets": { "structure": "bridged", "origin": "distributed", "edge": "organic", "layers": "third",
                  "space": "2d", "timing": "eased", "tone": ["clean"], "function": ["section-break"], "also": [] },
      "duration": { "default": 96, "min": 48, "max": 150 },   // frames at 30 fps
      "overlay": true,                                         // has an alpha overlay for editing apps
      "requires": ["webgl2"],
      "params": [{ "name": "color", "type": "color", "default": "#FF4F1A", "description": "…" }],
      "presets": [{ "id": "ink", "name": "Black liquid", "params": { "color": "#111111" } }],
      "authors": ["GTKottman"],
      "media": {
        "preview": "<mediaBase>/liquid-fill@1.0.0.mp4",        // 1920×1080 h264, scene A → transition → scene B
        "preview720": "<mediaBase>/liquid-fill@1.0.0-720.mp4", // 1280×720, for grids
        "poster": "<mediaBase>/liquid-fill@1.0.0.jpg",         // 35% into the transition
        "overlay": "<mediaBase>/liquid-fill@1.0.0-overlay.mov" // ProRes 4444 with alpha; only if overlay is true
      },
      "source": "https://github.com/GTKottman/remotion-transitions/tree/main/transitions/04-cover/organic/liquid-fill"
    }
  ]
}
```

Facet values always come from the vocabulary in `taxonomy.json` (`facets`), so they can be used
directly as filters. Families and subfamilies are listed in taxonomy order; transitions are sorted
by family, then subfamily, then id.

## Showing the previews

- Use `preview720` in grids (`<video muted loop playsinline preload="none" poster=…>`) and `preview`
  on a detail page. Every preview is 24 frames of scene A, the transition, then 24 frames of scene B.
- Media for a new version appear a few minutes after its merge (the media workflow renders and
  uploads them). If a request for the current version fails, fall back to the poster or hide the card.
- GitHub release downloads redirect to a CDN. Browsers follow that automatically; server-side fetches
  must follow redirects.

## Parameters

`params[].type` is one of: `number`, `integer` (both with `min`/`max`), `boolean`, `string`,
`color` (hex), `colors` (list of hex), `enum` (with `options`). That is enough to build a form for
each transition.
